# Roman-Microlensing-Mass-Distance

This code plots different constraints of observables for the lens mass and distance of a microlensing event, as well as the uncertainties for the constraints. We use 3 fiducial systems to analyze how the resulting constraints on the mass and distance change depending on the mass and location of the lens star.

To use this code, you only need the numpy and matplotlib packages.
